# Security policy

## Supported versions

Security fixes are provided for the latest stable major release.

| Version | Supported |
|---|---|
| 2.x | Yes |
| 0.x–1.x | No |

## Reporting a vulnerability

Email `benyaminrmb@gmail.com` with a description, affected versions, reproduction steps, and potential impact. Do not create a public issue before a fix is available.

You should receive an acknowledgement within seven days. Valid reports will be investigated privately, patched in a coordinated release, and credited when requested.

Never include production credentials, personal data, or data obtained from systems you do not own in a report.
